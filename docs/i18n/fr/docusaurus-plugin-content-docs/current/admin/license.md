# Licence et droits d'auteur {#license}

## Conditions de licence {#license-terms}

OpenVLE est publié sous la **GNU Affero General Public License Version 3 (AGPLv3)**. L'AGPLv3 est une licence de logiciel libre de la Free Software Foundation (FSF), basée sur la GPL v3, qui garantit en outre que le code source reste disponible même en cas d'utilisation via un réseau.

### Conditions de l'AGPLv3 {#agplv3-conditions}

- La redistribution du logiciel doit s'effectuer sous les mêmes conditions de licence
- Les modifications du logiciel doivent être divulguées et publiées sous les mêmes conditions de licence
- Le code source doit être fourni lorsque le logiciel est rendu accessible via un réseau
- Les utilisateurs doivent être informés des conditions de licence et avoir la possibilité de consulter une copie de la licence

Les conditions complètes de la licence sont disponibles à l'adresse https://www.gnu.org/licenses/agpl-3.0.en.html#license-text.

### Qu'est-ce que cela signifie pour vous ? {#what-it-means}

En tant qu'utilisateur, vous avez le droit d'exécuter, de copier, de distribuer, d'étudier, de modifier et d'améliorer le logiciel. Vous devez toutefois veiller à respecter les conditions de l'AGPLv3 — en particulier si vous apportez des modifications au logiciel ou si vous rendez le logiciel accessible via un réseau.
