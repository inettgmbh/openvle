# Infrastructure

La section **Infrastructure** offre une vue d'ensemble centralisée de toutes les données relatives aux fabricants et aux systèmes dans OpenVLE.  
Vous y gérez les **fabricants**, les **applications** et les **systèmes d'exploitation** utilisés dans les machines virtuelles (VM) ou les modèles de VM.  
Ces informations servent à la saisie structurée, à la documentation et à la traçabilité au sein du logiciel de gestion.

## Exemple ou cas d'utilisation

<Example title="Attribution traçable de logiciels à une VM">
  Une administratrice souhaite documenter quels logiciels sont installés sur une
  VM de formation. Elle ouvre la section **Infrastructure → Applications**, y
  crée l'application « LibreOffice 7.6 » et l'attribue ensuite au modèle de VM «
  Debian12-Formation ». Il est ainsi possible de vérifier à tout moment quels
  logiciels sont présents sur quelles VM ou modèles de VM.
</Example>

## Remarques / Particularités

:::info
Les fonctionnalités présentées ici servent exclusivement à l'**inventaire** des VM et modèles de VM.  
**Aucune installation automatique** d'applications n'est effectuée au sein des systèmes.

Si vous avez besoin d'applications dans une VM ou un modèle de VM, vous devez continuer à les installer manuellement.  
Ce n'est qu'après avoir terminé la configuration que la VM ou le modèle de VM devrait être attribué aux entrées correspondantes dans OpenVLE.
:::

Cette séparation entre inventaire et installation garantit une traçabilité claire et évite les modifications involontaires sur les systèmes productifs.
