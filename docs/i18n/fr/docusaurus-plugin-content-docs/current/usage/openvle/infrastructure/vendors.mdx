# Fabricants

Dans la section **Fabricants**, vous gérez les fournisseurs, organisations ou développeurs dont proviennent les applications ou les systèmes d'exploitation.  
Ces informations servent à la **catégorisation**, à la **traçabilité** et au **filtrage** au sein de l'infrastructure OpenVLE.

## Créer un fabricant

1. Ouvrez dans le menu principal la section **Infrastructure → Fabricants**.
2. Cliquez sur **Ajouter** pour créer un nouveau fabricant.
3. Indiquez un **nom** et une **description** pour le fabricant.
4. Enregistrez le fabricant.
5. Basculez ensuite dans l'onglet **Applications** ou **Systèmes d'exploitation** pour ajouter les objets souhaités.

---

## Modifier un fabricant

1. Ouvrez dans le menu principal la section **Infrastructure → Fabricants**.
2. Recherchez le fabricant souhaité dans la liste.
3. Cliquez sur **Modifier**, ou ouvrez le menu contextuel du fabricant et sélectionnez **Modifier**.
4. Le formulaire affiche toutes les données actuelles du fabricant.
5. Adaptez les champs souhaités, par exemple le **nom** ou la **description**.
6. Enregistrez les modifications.

---

## Supprimer un fabricant

1. Ouvrez dans le menu principal la section **Infrastructure → Fabricants**.
2. Recherchez le fabricant souhaité dans la liste.
3. Cliquez sur **Supprimer**, ou ouvrez le menu contextuel du fabricant et sélectionnez **Supprimer**.
4. Confirmez la suppression dans le dialogue affiché.
5. Le fabricant est alors définitivement supprimé.

:::warning
Seuls les fabricants qui ne sont plus attribués à aucune application ni aucun système d'exploitation peuvent être supprimés.
:::

## Exemple ou cas d'utilisation

<Example title="Créer un fabricant pour une nouvelle application">
  Une administratrice souhaite créer une nouvelle application provenant d'un fabricant non encore enregistré.  
  Elle ouvre la section **Infrastructure → Fabricants**, clique sur **Ajouter** et saisit :
  - Nom : *The Document Foundation*  
  - Description : *Organisation à but non lucratif derrière LibreOffice*

Ce fabricant peut ensuite être sélectionné directement lors de la création de l'application « LibreOffice ».

</Example>

## Remarques / Particularités

- Les fabricants sont associés aux applications et aux systèmes d'exploitation.
- Une gestion cohérente des fabricants facilite les filtrages et les rapports ultérieurs.
- Il est recommandé de garder les noms de fabricants univoques (par ex. « Microsoft Corporation » plutôt que simplement « Microsoft »).
