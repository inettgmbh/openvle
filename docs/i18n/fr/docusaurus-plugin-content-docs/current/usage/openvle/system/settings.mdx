# Paramètres

Dans la section **Paramètres**, vous gérez les paramètres et configurations système globaux qui contrôlent le comportement d'OpenVLE.  
Les administratrices et administrateurs peuvent y définir des options fondamentales, telles que le comportement du système ou les intégrations avec des services externes.

## Modifier un paramètre

1. Ouvrez dans le menu principal la section **Système → Paramètres**.
2. Recherchez le paramètre souhaité dans la liste.
3. Cliquez sur **Modifier**.
4. Le formulaire affiche toutes les données actuelles du paramètre.
5. Ajustez la valeur selon vos besoins.
6. Enregistrez les modifications.
7. Les modifications prennent généralement effet **immédiatement**.

:::warning
Les paramètres avec la visibilité `internal` ne peuvent **pas** être modifiés.
:::

## Remarques / Particularités

- Les modifications des paramètres prennent effet immédiatement sur l'ensemble du système.
- Les valeurs sensibles comme les clés API ou les mots de passe sont partiellement masquées pour des raisons de sécurité.
- Des modifications incorrectes peuvent provoquer un comportement inattendu – veuillez procéder avec prudence.
- Certaines configurations nécessitent un redémarrage des services ou des workers après modification. Cela est indiqué dans la description du paramètre.
- Les valeurs sont stockées de manière persistante et sont conservées même après des mises à jour ou des redémarrages.
