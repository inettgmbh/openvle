# Système

La section **Système** regroupe toutes les fonctions centrales d'administration et d'arrière-plan d'OpenVLE.  
Vous y trouverez les journaux système, les tâches, les configurations et les activités qui concernent le comportement et le fonctionnement de l'ensemble de la plateforme.

## Exemple ou cas d'utilisation

<Example title="Vérifier les activités système">
  Une administratrice souhaite savoir quand des utilisateurs ont effectué des
  modifications sur les modèles de VM pour la dernière fois. Elle ouvre la
  section **Système → Activités** et filtre par l'objet « Modèles de VM ». Elle
  peut ensuite voir précisément quel utilisateur a effectué quelle action et à
  quel moment.

## Remarques / Particularités

- La section Système n'est généralement visible que pour les utilisateurs disposant de permissions étendues.
- Les modifications des paramètres globaux affectent tous les utilisateurs.
- Les tâches et les activités peuvent être utilisées pour analyser des problèmes ou surveiller l'état du système.
- La journalisation est continue – les entrées plus anciennes peuvent être automatiquement supprimées après des délais de conservation définis.
