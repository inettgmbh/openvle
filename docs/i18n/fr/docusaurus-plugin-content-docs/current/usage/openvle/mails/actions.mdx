# Actions e-mail

Dans la section **Actions**, vous trouverez un aperçu de tous les événements internes au système pour lesquels OpenVLE peut envoyer automatiquement des e-mails.  
Chaque action représente un événement concret dans le système, comme la création d'une machine virtuelle, le démarrage d'un événement ou la fin d'un événement.  
L'attribution d'un modèle d'e-mail à une action détermine quel message est envoyé dans ce cas.

Si aucun modèle d'e-mail n'est attribué à une action, **aucun e-mail** n'est envoyé lorsque cette action se produit.

## Attribuer un modèle d'e-mail {#assign-template}

1. Ouvrez la section **E-mails -> Actions** dans le menu principal.
2. Recherchez l'action souhaitée dans la liste.
3. Ouvrez l'action.
4. Rendez-vous dans l'onglet **Modèles d'e-mail** et cliquez sur **Attribuer**.
5. Recherchez le modèle d'e-mail souhaité et sélectionnez-le.
6. Enregistrez l'attribution.

:::info
Lorsqu'**un** modèle d'e-mail est attribué à une action, cela est indiqué dans la vue détaillée du modèle d'e-mail en haut à droite par un **symbole vert**.
:::

---

## Retirer un modèle d'e-mail {#remove-template}

1. Ouvrez la section **E-mails -> Actions** dans le menu principal.
2. Recherchez l'action souhaitée dans la liste.
3. Ouvrez l'action.
4. Rendez-vous dans l'onglet **Modèles d'e-mail**.
5. Cliquez sur **Retirer** pour le modèle d'e-mail à retirer, ou ouvrez le menu contextuel et sélectionnez **Retirer**.
6. Confirmez l'opération dans la boîte de dialogue affichée.

:::info
Lorsqu'**aucun** modèle d'e-mail n'est attribué à une action, cela est indiqué dans la vue détaillée du modèle d'e-mail en haut à droite par un **symbole rouge**.
:::

## Exemple ou cas d'utilisation {#example}

<Example title="Action e-mail pour les machines virtuelles déployées">
  Après la création d'une nouvelle machine virtuelle, un e-mail doit être envoyé
  automatiquement. Ouvrez dans la section **E-mails -> Actions** l'action
  *"VirtualMachine a été déployée avec succès"* et attribuez-lui le modèle
  *"VirtualMachine a été déployée avec succès"*. Désormais, lors de la création
  d'une nouvelle machine virtuelle, cet e-mail sera automatiquement envoyé.

## Remarques / Particularités {#notes}

- Les actions sont prédéfinies par le système et ne peuvent pas être créées ou supprimées manuellement.
- Si aucun modèle n'est attribué à une action, aucun envoi d'e-mail n'a lieu.
- Les modifications du modèle attribué prennent effet immédiatement pour les événements futurs.
- Les actions sont généralement regroupées par domaine (par ex. utilisateurs, environnements, événements, système).
- Certaines actions sont purement internes et servent à la journalisation, sans fonction d'envoi.
