# E-mails envoyés

Dans la section **Envoyés**, vous trouverez une vue d'ensemble de tous les e-mails envoyés par le système.  
Vous pouvez y vérifier quand, à qui et avec quel modèle un message a été envoyé, par ex. des notifications concernant des événements ou des machines virtuelles.

Cette vue d'ensemble sert de preuve et de contrôle si des utilisateurs indiquent ne pas avoir reçu un message attendu, ou si vous souhaitez vérifier qu'un envoi spécifique a bien été effectué.

## Remarques / Particularités

- Les e-mails échoués peuvent être renvoyés si nécessaire.
- Les e-mails envoyés sont conservés pendant une durée définie puis automatiquement supprimés, voir [Administration -> Installation -> Configuration](/docs/admin/install/configuration).
- Pour de grandes quantités d'e-mails système (par ex. démarrage d'événement), l'envoi s'effectue par lots (_bulk send_).
- L'envoi effectif des e-mails s'effectue de manière asynchrone via le processus task-worker.
- Dans la fenêtre de détail d'un e-mail, le nom du modèle d'e-mail utilisé et le destinataire sont directement consultables.
