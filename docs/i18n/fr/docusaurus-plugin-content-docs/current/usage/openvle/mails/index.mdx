# E-mails

OpenVLE peut envoyer automatiquement des e-mails aux utilisateurs, par exemple lors de la création de VM ou au démarrage d'événements.  
Dans la section E-mails, vous trouverez aussi bien tous les messages envoyés que les modèles d'e-mail utilisés pour les messages système, ainsi que toutes les actions e-mail existantes.

## Remarques / Particularités

- Les e-mails sont envoyés de manière asynchrone via des tâches en arrière-plan (tasks).
- Les envois échoués peuvent être renvoyés depuis la vue d'ensemble.
- Chaque e-mail est associé au modèle correspondant -- les modifications apportées aux modèles ne s'appliquent qu'aux futurs e-mails.
- Le texte de l'e-mail peut contenir des espaces réservés dynamiques (par ex. `{user.name}`, `{event.name}`) qui sont remplacés lors de l'envoi.
- Le serveur SMTP peut être configuré individuellement, voir [Administration -> Installation -> Configuration](/docs/admin/install/configuration).
