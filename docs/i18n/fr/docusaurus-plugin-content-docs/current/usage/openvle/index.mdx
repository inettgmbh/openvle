# OpenVLE

OpenVLE est un logiciel de gestion en ligne conçu pour organiser et piloter efficacement des infrastructures informatiques complexes.  
Il permet la gestion centralisée de **machines virtuelles**, d'**utilisateurs**, d'**environnements** et d'**événements** dans une interface unique et intuitive.  
Même les utilisateurs ayant peu de connaissances techniques peuvent utiliser OpenVLE sans difficulté.

OpenVLE intègre des technologies modernes telles que **Proxmox VE**, **Apache Guacamole**, **Cloud-Init** et le **Qemu Guest Agent** pour provisionner et gérer automatiquement les environnements virtuels.  
Ainsi, plusieurs utilisateurs peuvent accéder simultanément aux machines virtuelles — de manière sécurisée, efficace et sans installation de logiciel supplémentaire.

## Où trouver cette section ?

Après la connexion, vous accédez directement au **tableau de bord** d'OpenVLE.  
De là, vous pouvez accéder à toutes les sections via le **menu principal à gauche** — par exemple :

- **Contrôle d'accès** pour les utilisateurs, rôles et permissions
- **Environnements** et **événements** pour les environnements d'apprentissage
- **Machines virtuelles** et **modèles** pour la gestion technique
- **Système** et **e-mails** pour les paramètres et les notifications

## Guide pas à pas

Voici comment démarrer avec OpenVLE :

1. **Se connecter :** Connectez-vous avec votre compte utilisateur.
2. **Explorer le tableau de bord :** Consultez les tâches ouvertes, les événements planifiés et les activités récentes.
3. **Gérer les machines virtuelles :** Ouvrez la section _Machines virtuelles_ pour créer ou démarrer de nouvelles instances.
4. **Créer des environnements :** Regroupez des modèles et des VMs dans un environnement afin de les mettre à disposition dans des événements.
5. **Vérifier les permissions :** Attribuez des rôles et des droits d'accès pour contrôler l'utilisation.

## Remarques / Particularités

- Les modifications dans OpenVLE sont enregistrées automatiquement.
- Certaines actions (par ex. création de VM ou opérations en masse) sont exécutées en arrière-plan sous forme de **tâches**.
- Via le **journal des activités**, vous pouvez retracer toutes les modifications.
- Si certaines sections sont grisées, il vous manque probablement les permissions correspondantes.
- Toutes les actions des utilisateurs sont journalisées afin de garantir la transparence et la sécurité.
