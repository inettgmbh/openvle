# Tableau de bord

Après la connexion, vous accédez au **tableau de bord** — la page d'accueil centrale d'**OpenVLE**.  
Vous y obtenez en un coup d'oeil l'accès à vos ressources, activités et systèmes les plus importants.

## Accès aux ressources

Le contenu affiché sur le tableau de bord dépend de vos droits d'utilisateur :

- **Ressources personnelles :** Vous ne voyez que vos objets personnels (par ex. vos propres VMs ou environnements).
- **Ressources de l'organisation :** En tant qu'administrateur, vous voyez toutes les ressources du système.
- **Vue globale :** Avec des rôles étendus (par ex. support système ou superutilisateur), vous avez accès à des informations avancées.

> Ainsi, vous ne voyez toujours que les contenus pertinents pour votre rôle.

## Remarques / Particularités

- Le tableau de bord est adapté individuellement aux permissions de l'utilisateur connecté.
- Les notifications à l'échelle du système sont également affichées ici.
- Certains modules (par ex. activités ou tâches) ne sont affichés que si les permissions correspondantes sont disponibles.
- Pour les liens externes (par ex. système de tickets, Confluence), les droits d'accès du système cible respectif s'appliquent toujours.
