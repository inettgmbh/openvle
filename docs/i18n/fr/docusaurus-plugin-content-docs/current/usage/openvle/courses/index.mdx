# Environnements

Dans OpenVLE, les **environnements** constituent la base technique et organisationnelle d'un événement.  
Un environnement définit **quels modèles de VM** sont utilisés et est généralement créé dans le cadre d'un événement. Il détermine les ressources mises à la disposition des participants.

## Créer un environnement

1. Ouvrez dans le menu principal la section **Environnements**.
2. Cliquez sur **Ajouter** pour créer un nouvel environnement.
3. Saisissez un **nom** et une **description** pour l'environnement.
4. Enregistrez l'environnement.
5. Dans l'onglet **Modèles de VM**, vous pouvez maintenant ajouter ou retirer les modèles de VM nécessaires de l'environnement.
6. Utilisez cet environnement pour préparer de nouveaux événements.

---

## Modifier un environnement

1. Ouvrez dans le menu principal la section **Environnements**.
2. Recherchez l'environnement souhaité dans la liste.
3. Cliquez sur **Modifier** ou ouvrez le menu contextuel de l'environnement et sélectionnez **Modifier**.
4. Le formulaire affiche toutes les données actuelles de l'environnement.
5. Ajustez les champs souhaités, par ex. le nom ou la description.
6. Enregistrez les modifications.
7. Dans l'onglet **Modèles de VM**, vous pouvez ajouter ou retirer les modèles de VM nécessaires de l'environnement.

:::warning
Les modifications apportées à un environnement (y compris les modèles de VM attribués) affectent tous les événements **planifiés** qui utilisent cet environnement. Lors du déploiement, l'événement est mis à disposition avec la version actuelle de l'environnement.

Les événements **actifs** ne sont pas affectés : lors du déploiement, une relation directe entre l'événement et les modèles de VM est créée, de sorte que l'événement est à partir de ce moment découplé de l'environnement.
:::

---

## Supprimer un environnement

1. Ouvrez dans le menu principal la section **Environnements**.
2. Recherchez l'environnement souhaité dans la liste.
3. Cliquez sur **Supprimer** ou ouvrez le menu contextuel de l'environnement et sélectionnez **Supprimer**.
4. Confirmez la suppression dans la boîte de dialogue affichée.
5. L'environnement est alors définitivement supprimé.

:::danger
Un environnement ne peut être supprimé que lorsqu'aucun événement ne lui est plus attribué.
:::

## Remarques / Particularités

- Les environnements peuvent être associés à plusieurs **événements**.
- Un environnement peut contenir plusieurs modèles de VM.
- Les modifications apportées à un environnement affectent tous les événements **planifiés** qui utilisent cet environnement. Les événements déjà actifs restent inchangés, car lors du déploiement, une relation directe entre l'événement et les modèles de VM est créée.
- La suppression d'un environnement n'est possible que lorsqu'aucun événement ne lui est plus attribué.
- Seuls les utilisateurs disposant des permissions appropriées peuvent modifier ou supprimer des environnements.
