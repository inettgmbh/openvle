# Tags

Les tags sont des mots-clés permettant de catégoriser, filtrer et retrouver plus facilement des objets (par ex. environnements, modèles de VM ou machines virtuelles).  
Ils aident à structurer de manière claire de grandes quantités de données et à regrouper les objets par thématique.

## Créer un tag

1. Ouvrez dans le menu principal la section de l'objet souhaité.
2. Recherchez l'objet souhaité dans la liste et ouvrez-le.
3. Dans la vue détaillée de l'objet, il y a une section **Tags**.
4. Cliquez sur le bouton Plus pour ajouter un nouveau tag.
5. Indiquez un **nom** et une **valeur** pour le tag.
6. Enregistrez le tag.

---

## Supprimer un tag

1. Ouvrez dans le menu principal la section de l'objet souhaité.
2. Recherchez l'objet souhaité dans la liste et ouvrez-le.
3. Dans la vue détaillée de l'objet se trouve une section **Tags**.
4. Cliquez sur le bouton X à côté du tag à supprimer.
5. Confirmez la suppression dans le dialogue affiché.

## Remarques / Particularités

- Les tags peuvent être utilisés plusieurs fois et attribués simultanément à plusieurs objets.
- Lors de la suppression d'un objet, les tags attribués sont automatiquement retirés.
- Les tags sont indépendants des rôles utilisateur -- tous les utilisateurs disposant des permissions appropriées peuvent les voir et les utiliser.
- Le système de tags est universel et prend en charge la quasi-totalité des modèles d'objets dans OpenVLE.
