# Modèles de connexion

Les modèles de connexion définissent dans **OpenVLE** des paramètres réutilisables pour les connexions.  
Ils permettent de stocker de manière standardisée des paramètres de connexion tels que le **protocole**, le **port**, le **nom d'utilisateur** ou le **mot de passe**, afin que les administrateurs puissent créer rapidement et de manière cohérente de nouvelles connexions.

## Créer un modèle de connexion

1. Ouvrez dans le menu principal la section **Connexions → Modèles**.
2. Cliquez sur **Ajouter** pour créer un nouveau modèle de connexion.
3. Sélectionnez le **protocole** souhaité (par ex. RDP ou SSH).
4. Indiquez les paramètres par défaut tels que le **port**, le **nom d'utilisateur** et le **mot de passe**.
5. Enregistrez le modèle.
6. Utilisez ensuite le modèle lors de la création de nouvelles connexions.

:::info
Les modèles de connexion ne peuvent **pas être modifiés**, mais uniquement **recréés**.
:::

---

## Supprimer un modèle de connexion

1. Ouvrez dans le menu principal la section **Connexions → Modèles**.
2. Recherchez le modèle souhaité dans la liste.
3. Cliquez sur **Supprimer**, ou ouvrez le menu contextuel et sélectionnez **Supprimer**.
4. Confirmez la suppression dans le dialogue affiché.
5. Le modèle de connexion est alors définitivement supprimé.

:::warning
Les modèles de connexion ne peuvent être **supprimés que si aucune connexion** n'existe encore pour ce modèle.  
Si des connexions dépendantes existent encore, celles-ci doivent d'abord être supprimées avant que le modèle puisse être retiré.
:::

---

## Duplication automatique

Lors de la création d'une nouvelle VM, tous les **modèles de connexion** attribués au **modèle de VM** utilisé sont automatiquement dupliqués et attribués à la VM nouvellement créée.  
Les modèles de connexion ainsi générés peuvent être utilisés pour établir des connexions vers la VM, que ce soit manuellement ou dans le cadre d'un événement.

## Exemple ou cas d'utilisation

<Example title="Créer un modèle RDP standard pour les environnements de formation">
  Une administratrice souhaite s'assurer que toutes les VM de formation sont
  créées avec les mêmes paramètres RDP. Dans la section **Modèles de
  connexion**, elle crée un nouveau modèle, sélectionne le protocole **RDP** et
  saisit les identifiants de connexion. Par la suite, de nouvelles connexions
  peuvent être créées sur la base de ce modèle de connexion, liées aux
  utilisateurs ou VM correspondants.
</Example>

## Remarques / Particularités

- Les modèles de connexion ne peuvent pas être modifiés, mais uniquement recréés.
- Les modèles servent à l'uniformisation et accélèrent le déploiement de nouvelles VM ou connexions utilisateur.
- Les connexions existantes conservent leurs paramètres individuels.
- Via la liste des modèles de connexion, il est possible de vérifier quelles VM ou connexions utilisent un modèle donné.
- Seuls les administrateurs ou les utilisateurs disposant des permissions appropriées peuvent créer ou supprimer des modèles de connexion.
