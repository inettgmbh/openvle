# Connexions

Dans **OpenVLE**, les configurations de connexion definissent **comment** les utilisateurs peuvent se connecter aux machines virtuelles ou aux modeles de VM -- par exemple via **RDP** ou **SSH**.  
Ces connexions sont gerees de maniere centralisee et permettent un acces securise via navigateur grace a **Apache Guacamole**.

Dans la section **Connexions**, vous pouvez consulter les configurations existantes, creer de nouvelles connexions et les attribuer a des utilisateurs ou des machines virtuelles specifiques.

## Exemple ou cas d'utilisation

<Example title="Creer une connexion RDP pour une machine virtuelle">
  Une administratrice souhaite permettre aux utilisateurs d'acceder a une
  nouvelle VM Windows. Dans la section **Connexions**, elle cree un nouveau
  **modele de connexion** avec le protocole **RDP**, renseigne les identifiants
  d'acces et l'associe a la VM correspondante. Ensuite, elle cree de nouvelles
  connexions basees sur ce modele, attribuees a des utilisateurs individuels.
  Ces utilisateurs peuvent desormais se connecter a la VM directement via le
  navigateur -- de maniere securisee et sans logiciel RDP local.
</Example>

## Remarques / Particularites

- Les connexions sont **gerees de maniere centralisee** dans OpenVLE et sont **independantes du compte utilisateur**.
- Les connexions ne peuvent **pas etre modifiees**, mais uniquement **supprimees et recreees**.
- Les **modeles de connexion** servent a standardiser les configurations recurrentes.
- Seuls les utilisateurs disposant des **permissions** appropriees peuvent modifier les parametres de connexion ou les identifiants d'acces.
- Les sessions actives peuvent etre surveillees via le **serveur Apache Guacamole**.
- Les **modeles de connexion** et les **modeles de VM** sont deux types d'objets distincts, chacun ayant sa propre fonction et attribution.
