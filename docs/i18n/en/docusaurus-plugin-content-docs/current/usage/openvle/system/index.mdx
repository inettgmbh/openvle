# System

The **System** section covers all central administration and background functions of OpenVLE.  
Here you will find system-wide logs, tasks, configurations, and activities that affect the behavior and operation of the entire platform.

## Notes / Special considerations

- The System section is generally only visible to users with elevated permissions.
- Changes to global settings affect all users.
- Tasks and activities can be used to analyze problems or monitor system health.
- Logging is continuous – older entries may be automatically deleted after defined retention periods.
