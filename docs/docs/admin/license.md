# Lizenz und Urheberrecht {#license}

## Lizenzbedingungen {#license-terms}

OpenVLE wird unter der **GNU Affero General Public License Version 3 (AGPLv3)** veröffentlicht. Die AGPLv3 ist eine freie Softwarelizenz der Free Software Foundation (FSF), die auf der GPL v3 basiert und zusätzlich sicherstellt, dass der Quellcode auch bei Nutzung über ein Netzwerk verfügbar bleibt.

### Bedingungen der AGPLv3 {#agplv3-conditions}

- Die Weitergabe der Software muss unter denselben Lizenzbedingungen erfolgen
- Änderungen an der Software müssen offengelegt und unter denselben Lizenzbedingungen freigegeben werden
- Der Quellcode muss bereitgestellt werden, wenn die Software über ein Netzwerk zugänglich gemacht wird
- Die Nutzer müssen über die Lizenzbedingungen informiert werden und die Möglichkeit haben, eine Kopie der Lizenz einzusehen

Die vollständigen Lizenzbedingungen findest du unter https://www.gnu.org/licenses/agpl-3.0.en.html#license-text.

### Was bedeutet das für dich? {#what-it-means}

Als Benutzer hast du das Recht, die Software auszuführen, zu kopieren, zu verbreiten, zu studieren, zu ändern und zu verbessern. Du musst jedoch sicherstellen, dass du die Bedingungen der AGPLv3 einhältst — insbesondere wenn du Änderungen an der Software vornimmst oder die Software über ein Netzwerk zugänglich machst.
