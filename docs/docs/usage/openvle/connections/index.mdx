# Verbindungen

In **OpenVLE** definieren Verbindungskonfigurationen, **wie** sich Benutzerinnen und Benutzer mit virtuellen Maschinen oder VM-Vorlagen verbinden können – beispielsweise über **RDP** oder **SSH**.  
Diese Verbindungen werden zentral verwaltet und ermöglichen einen sicheren, webbasierten Zugriff über **Apache Guacamole**.

Im Bereich **Verbindungen** kannst du bestehende Konfigurationen einsehen, neue Verbindungen anlegen und diese bestimmten Benutzern oder virtuellen Maschinen zuweisen.

## Beispiel oder Anwendungsfall

<Example title="RDP-Verbindung für eine virtuelle Maschine anlegen">
  Eine Administratorin möchte Benutzerinnen und Benutzern Zugriff auf eine neue
  Windows-VM ermöglichen. Sie erstellt im Bereich **Verbindungen** eine neue
  **Verbindungsvorlage** mit dem Protokoll **RDP**, hinterlegt die Zugangsdaten
  und verknüpft diese mit der entsprechenden VM. Anschließend erstellt sie
  basierend auf dieser Vorlage neue Verbindungen, die einzelnen Benutzern
  zugewiesen werden. Diese Benutzer können sich nun direkt über den Browser mit
  der VM verbinden – sicher und ohne lokale RDP-Software.
</Example>

## Hinweise / Besonderheiten

- Verbindungen werden in OpenVLE **zentral verwaltet** und sind **unabhängig vom Benutzerkonto**.
- Verbindungen können **nicht bearbeitet**, sondern nur **gelöscht und neu erstellt** werden.
- **Verbindungsvorlagen** dienen der Standardisierung wiederkehrender Konfigurationen.
- Nur Benutzer mit entsprechenden **Berechtigungen** können Verbindungseinstellungen oder Zugangsdaten ändern.
- Aktive Sitzungen können über den **Apache Guacamole-Server** überwacht werden.
- **Verbindungsvorlagen** und **VM-Vorlagen** sind zwei unterschiedliche Objekttypen mit jeweils eigener Funktion und Zuordnung.
