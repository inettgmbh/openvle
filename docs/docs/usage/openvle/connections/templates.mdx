# Verbindungsvorlagen

Verbindungsvorlagen definieren in **OpenVLE** wiederverwendbare Einstellungen für Verbindungen.  
Damit lassen sich Verbindungsparameter wie **Protokoll**, **Port**, **Benutzername** oder **Passwort** standardisiert hinterlegen, sodass Administratorinnen und Administratoren neue Verbindungen schnell und konsistent erstellen können.

## Erstellen einer Verbindungsvorlage

1. Öffne im Hauptmenü den Bereich **Verbindungen → Vorlagen**.
2. Klicke auf **Hinzufügen**, um eine neue Verbindungsvorlage zu erstellen.
3. Wähle das gewünschte **Protokoll** (z. B. RDP oder SSH) aus.
4. Gib Standardparameter wie **Port**, **Benutzername** und **Passwort** an.
5. Speichere die Vorlage.
6. Verwende die Vorlage anschließend beim Erstellen neuer Verbindungen.

:::info
Verbindungsvorlagen können **nicht bearbeitet**, sondern nur **neu erstellt** werden.
:::

---

## Löschen einer Verbindungsvorlage

1. Öffne im Hauptmenü den Bereich **Verbindungen → Vorlagen**.
2. Suche die gewünschte Vorlage in der Liste.
3. Klicke auf **Löschen**, oder öffne das Kontextmenü und wähle **Löschen**.
4. Bestätige den Löschvorgang im angezeigten Dialog.
5. Die Verbindungsvorlage wird daraufhin dauerhaft entfernt.

:::warning
Verbindungsvorlagen können **nur gelöscht werden**, wenn **keine Verbindungen** mehr zu dieser Vorlage existieren.  
Falls noch abhängige Verbindungen vorhanden sind, muss diese zunächst gelöscht werden, bevor die Vorlage entfernt werden kann.
:::

---

## Automatische Duplizierung

Beim Erstellen einer neuen VM werden alle **Verbindungsvorlagen**, die der verwendeten **VM-Vorlage** zugewiesen sind, automatisch dupliziert und der neu erstellten VM zugewiesen.  
So können die neu erzeugten Verbindungsvorlagen verwendet werden, um Verbindungen zur VM herzustellen – entweder manuell oder im Rahmen einer Veranstaltung.

<Example title="Standard-RDP-Vorlage für Schulungsumgebungen erstellen">

## Hinweise / Besonderheiten

- Verbindungsvorlagen können nicht bearbeitet, sondern nur neu erstellt werden.
- Vorlagen dienen der Vereinheitlichung und beschleunigen die Bereitstellung neuer VMs oder Benutzerverbindungen.
- Bestehende Verbindungen behalten ihre individuellen Einstellungen.
- Über die Liste der Verbindungsvorlagen kann nachvollzogen werden, welche VMs oder Verbindungen eine bestimmte Vorlage verwenden.
- Nur Administratorinnen und Administratoren oder Benutzer mit entsprechenden Berechtigungen dürfen Verbindungsvorlagen anlegen oder löschen.
