# Infrastruktur

Der Bereich **Infrastruktur** bietet eine zentrale Übersicht über alle hersteller- und systembezogenen Daten in OpenVLE.  
Hier verwaltest du **Hersteller**, **Anwendungen** und **Betriebssysteme**, die in virtuellen Maschinen (VMs) oder VM-Vorlagen verwendet werden.  
Diese Informationen dienen der strukturierten Erfassung, Dokumentation und Nachverfolgbarkeit innerhalb der Verwaltungssoftware.

## Beispiel oder Anwendungsfall

<Example title="Nachvollziehbare Softwarezuordnung zu einer VM">
  Eine Administratorin möchte dokumentieren, welche Software auf einer
  Schulungs-VM installiert ist. Sie öffnet den Bereich **Infrastruktur →
  Anwendungen**, legt dort die Anwendung „LibreOffice 7.6“ an und weist diese
  anschließend der VM-Vorlage „Debian12-Schulung“ zu. Dadurch ist jederzeit
  nachvollziehbar, welche Software auf welchen VMs oder VM-Vorlagen vorhanden
  ist.
</Example>

## Hinweise / Besonderheiten

:::info
Die hier aufgeführten Funktionen dienen ausschließlich der **Inventarisierung** von VMs und VM-Vorlagen.  
Es erfolgt **keine automatische Installation** von Anwendungen innerhalb der Systeme.

Wenn du Anwendungen in einer VM oder VM-Vorlage benötigst, musst du diese weiterhin manuell installieren.  
Erst nach Abschluss der Konfiguration sollte die VM oder VM-Vorlage den passenden Einträgen in OpenVLE zugewiesen werden.
:::

Diese Trennung zwischen Inventarisierung und Installation sorgt für klare Nachvollziehbarkeit und verhindert unbeabsichtigte Änderungen an produktiven Systemen.
