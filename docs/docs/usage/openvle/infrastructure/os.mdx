# Betriebssysteme

Im Bereich **Betriebssysteme** verwaltest du alle Betriebssysteme, die in OpenVLE als Grundlage für virtuelle Maschinen und VM-Vorlagen dienen.  
Hier definierst du, welche Systeme verfügbar sind, und kannst diese bestimmten Herstellern zuordnen, um die Softwarelandschaft strukturiert zu dokumentieren.

## Erstellen eines Betriebssystems

1. Öffne im Hauptmenü den Bereich **Infrastruktur → Betriebssysteme**.
2. Klicke auf **Hinzufügen**, um ein neues Betriebssystem zu erstellen.
3. Gib einen **Namen**, einen **Hersteller** und eine **Beschreibung** für das Betriebssystem an.
4. Speichere das Betriebssystem.
5. Ab sofort kannst du beim Erstellen von **VMs** oder **VM-Vorlagen** das Betriebssystem auswählen.

:::info
Der erforderliche Hersteller muss vor dem Erstellen des Betriebssystems vorhanden sein.
:::

---

## Bearbeiten eines Betriebssystems

1. Öffne im Hauptmenü den Bereich **Infrastruktur → Betriebssysteme**.
2. Suche in der Liste nach dem gewünschten Betriebssystem.
3. Klicke auf **Bearbeiten**, oder öffne das Kontextmenü des Betriebssystems und wähle **Bearbeiten**.
4. Im Formular werden alle aktuellen Daten des Betriebssystems angezeigt.
5. Passe die gewünschten Felder an – beispielsweise **Name** oder **Beschreibung**.
6. Speichere die Änderungen.

:::note
Wenn eine Betriebssystemversion aktualisiert wurde, z. B. von _Debian 12_ auf _Debian 13_, wird empfohlen, ein **neues Betriebssystem** anzulegen.  
So wird verhindert, dass bereits zugewiesene VMs und VM-Vorlagen von dieser Versionsänderung betroffen sind.  
Andernfalls erscheint es in OpenVLE so, als wären alle zugewiesenen Systeme auf die neue Version aktualisiert worden.
:::

---

## Löschen eines Betriebssystems

1. Öffne im Hauptmenü den Bereich **Infrastruktur → Betriebssysteme**.
2. Suche in der Liste nach dem gewünschten Betriebssystem.
3. Klicke auf **Löschen**, oder öffne das Kontextmenü des Betriebssystems und wähle **Löschen**.
4. Bestätige den Löschvorgang im angezeigten Dialog.
5. Das Betriebssystem wird daraufhin dauerhaft entfernt.

:::warning
Es können nur Betriebssysteme gelöscht werden, die keiner VM oder VM-Vorlage mehr zugewiesen sind.
:::

## Beispiel oder Anwendungsfall

<Example title="Neues Betriebssystem erfassen">
  Eine Administratorin möchte ein neues Betriebssystem für die Infrastruktur hinzufügen.  
  Sie öffnet den Bereich **Infrastruktur → Betriebssysteme**, klickt auf **Hinzufügen** und gibt ein:
  - Name: *Debian 12 (LTS)*  
  - Hersteller: *Debian Project*  
  - Beschreibung: *Standard-Linux-Distribution für Schulungsumgebungen*

Anschließend weist sie dieses Betriebssystem den passenden VM-Vorlagen zu, damit alle darauf basierenden VMs korrekt klassifiziert werden.

</Example>

---

## Hinweise / Besonderheiten

- Betriebssysteme werden **nicht automatisch installiert** – sie dienen ausschließlich der **Inventarisierung**.
- Ein Betriebssystem kann mit mehreren VM-Vorlagen oder VMs verknüpft werden.
- Hersteller müssen vorab existieren, um sie einem Betriebssystem zuordnen zu können.
- Eine eindeutige Namensgebung erleichtert die Filterung und spätere Auswertungen.
