# Dashboard

Nach dem Login gelangst du auf das **Dashboard** – die zentrale Startseite von **OpenVLE**.  
Hier erhältst du auf einen Blick Zugriff auf deine wichtigsten Ressourcen, Aktivitäten und Systeme.

## Zugriff auf Ressourcen

Welche Inhalte auf dem Dashboard erscheinen, hängt von deinen Benutzerrechten ab:

- **Eigene Ressourcen:** Du siehst nur deine persönlichen Objekte (z. B. eigene VMs oder Umgebungen).
- **Unternehmensressourcen:** Als Administratorin oder Administrator siehst du alle Ressourcen des Systems.
- **Globale Ansicht:** Mit erweiterten Rollen (z. B. Systembetreuung oder Superuser) erhältst du Zugriff auf erweiterte Informationen.

> So siehst du immer nur die Inhalte, die für deine Rolle relevant sind.

## Hinweise / Besonderheiten

- Das Dashboard ist individuell an die Berechtigungen des angemeldeten Benutzers angepasst.
- Systemweite Benachrichtigungen werden ebenfalls hier angezeigt.
- Bestimmte Module (z. B. Aktivitäten oder Tasks) werden nur eingeblendet, wenn entsprechende Berechtigungen vorhanden sind.
- Für externe Links (z. B. Ticketsystem, Confluence) gelten stets die Zugriffsrechte des jeweiligen Zielsystems.
