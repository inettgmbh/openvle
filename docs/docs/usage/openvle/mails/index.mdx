# E-Mails

OpenVLE kann automatisch E-Mails an Benutzerinnen und Benutzer senden – beispielsweise bei der Erstellung von VMs oder beim Start von Veranstaltungen.  
Im Bereich E-Mails findest du sowohl alle versendeten Nachrichten als auch die E-Mail-Vorlagen, die für Systemnachrichten verwendet werden, sowie alle vorhandenen E-Mail-Aktionen.

## Hinweise / Besonderheiten

- E-Mails werden asynchron über Hintergrundaufgaben (Tasks) versendet.
- Fehlgeschlagene Zustellungen können in der Übersicht erneut versendet werden.
- Jede E-Mail ist mit der entsprechenden Vorlage verknüpft – Änderungen an Vorlagen wirken sich erst auf zukünftige E-Mails aus.
- Der E-Mail-Text kann dynamische Platzhalter enthalten (z. B. `{user.name}`, `{event.name}`), die beim Versand ersetzt werden.
- Der SMTP-Server kann individuell konfiguriert werden, siehe [Administration -> Installation -> Konfiguration](/docs/admin/install/configuration).
