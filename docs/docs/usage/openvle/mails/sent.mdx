# Gesendete E-Mails

Im Bereich **Gesendet** findest du eine Übersicht aller vom System versendeten E-Mails.  
Hier kannst du nachvollziehen, wann, an wen und mit welcher Vorlage eine Nachricht versendet wurde – z. B. Benachrichtigungen über Veranstaltungen oder virtuelle Maschinen.

Diese Übersicht dient als Nachweis und Kontrolle, falls Benutzerinnen oder Benutzer angeben, eine erwartete Nachricht nicht erhalten zu haben, oder du prüfen möchtest, ob ein bestimmter Versand erfolgt ist.

## Hinweise / Besonderheiten

- Fehlgeschlagene E-Mails können bei Bedarf erneut versendet werden.
- Gesendete E-Mails werden für einen definierten Zeitraum gespeichert und danach automatisch gelöscht, siehe [Administration -> Installation -> Konfiguration](/docs/admin/install/configuration).
- Bei großen Mengen an Systemmails (z. B. Veranstaltungsstart) erfolgt der Versand stapelweise (_bulk send_).
- Der tatsächliche E-Mail-Versand erfolgt asynchron über den Task-Worker-Prozess.
- Im Detailfenster einer E-Mail ist der verwendete Name der E-Mail-Vorlage und der Empfänger direkt einsehbar.
