# Umgebungen

In OpenVLE bilden **Umgebungen** die fachliche und organisatorische Grundlage einer Veranstaltung.  
Eine Umgebung legt fest, **welche VM-Vorlagen** verwendet werden und werden in der Regel im Rahmen einer Veranstaltung erstellt und bestimmen, welche Ressourcen den Teilnehmerinnen und Teilnehmern zur Verfügung stehen.

## Erstellen einer Umgebung

1. Öffne im Hauptmenü den Bereich **Umgebungen**.
2. Klicke auf **Hinzufügen**, um eine neue Umgebungen zu erstellen.
3. Gib einen **Namen** und eine **Beschreibung** für die Umgebung an.
4. Speichere die Umgebung.
5. In dem Tab **VM-Vorlagen** kannst du nun die benötigten VM-Vorlagen zu der Umgebung hinzufügen oder entfernen.
6. Verwende diese Umgebung, um neue Veranstaltungen vorzubereiten.

---

## Bearbeiten einer Umgebung

1. Öffne im Hauptmenü den Bereich **Umgebungen**.
2. Suche in der Liste nach der gewünschten Umgebung.
3. Klicke auf **Bearbeiten** oder öffne das Kontextmenü der Umgebung und wähle **Bearbeiten**.
4. Im Formular werden alle aktuellen Daten der Umgebung angezeigt.
5. Passe die gewünschten Felder an – z. B. Name oder Beschreibung.
6. Speichere die Änderungen.
7. In dem Tab **VM-Vorlagen** kannst du die benötigten VM-Vorlagen zu der Umgebung hinzufügen oder entfernen.

:::warning
Änderungen an einer Umgebung (einschließlich der zugewiesenen VM-Vorlagen) wirken sich auf alle **geplanten** Veranstaltungen aus, die diese Umgebung verwenden. Beim Ausrollen wird die Veranstaltung mit der aktuellen Version der Umgebung bereitgestellt.

**Aktive** Veranstaltungen sind davon nicht betroffen: Beim Ausrollen wird eine direkte Beziehung zwischen der Veranstaltung und den VM-Vorlagen angelegt, sodass die Veranstaltung ab diesem Zeitpunkt von der Umgebung entkoppelt ist.
:::

---

## Löschen einer Umgebung

1. Öffne im Hauptmenü den Bereich **Umgebungen**.
2. Suche in der Liste nach der gewünschten Umgebung.
3. Klicke auf **Löschen** oder öffne das Kontextmenü der Umgebung und wähle **Löschen**.
4. Bestätige den Löschvorgang im angezeigten Dialog.
5. Die Umgebung wird daraufhin dauerhaft entfernt.

:::danger
Eine Umgebung kann erst gelöscht werden, wenn keine zugewiesenen Veranstaltungen mehr existieren.
:::

## Hinweise / Besonderheiten

- Umgebungen können mehreren **Veranstaltung** zugeordnet sein.
- Eine Umgebung kann mehrere VM-Vorlagen enthalten.
- Änderungen an einer Umgebung wirken sich auf alle **geplanten** Veranstaltungen aus, die diese Umgebung verwenden. Bereits aktive Veranstaltungen bleiben unverändert, da beim Ausrollen eine direkte Beziehung zwischen Veranstaltung und VM-Vorlagen erstellt wird.
- Das Löschen einer Umgebung ist erst möglich wenn keine zugewiesenen Veranstaltungen mehr existieren.
- Nur Benutzer mit entsprechenden Berechtigungen dürfen Umgebungen bearbeiten oder löschen.
