# Tags

Tags sind Schlagworte, mit denen Objekte (z. B. Umgebungen, VM-Vorlagen oder virtuelle Maschinen) kategorisiert, gefiltert und leichter gefunden werden können.  
Sie helfen, große Datenmengen übersichtlich zu strukturieren und Objekte thematisch zu gruppieren.

## Erstellen eines Tags

1. Öffne im Hauptmenü den Bereich des gewünschten Objekts.
2. Suche in der Liste nach dem gewünschten Objekt und öffne dieses.
3. In der Detailansicht des Objekts gibt es einen Abschnitt **Tags**.
4. Klicke auf den Plus Button um einen neuen Tag hinzuzufügen.
5. Gib einen **Namen** und einen **Wert** für den Tag an.
6. Speichere den Tag.

---

## Löschen eines Tags

1. Öffne im Hauptmenü den Bereich des gewünschten Objekts.
2. Suche in der Liste nach dem gewünschten Objekt und öffne es.
3. In der Detailansicht des Objekts befindet sich ein Abschnitt **Tags**.
4. Klicke auf den X Button neben dem zu löschenden Tag.
5. Bestätige den Löschvorgang im angezeigten Dialog.

<Example title="Kategorisierung von Umgebungen mit Tags">

## Hinweise / Besonderheiten

- Tags können mehrfach verwendet und mehreren Objekten gleichzeitig zugewiesen werden.
- Beim Löschen eines Objekts werden die zugewiesenen Tags automatisch entfernt.
- Tags sind unabhängig von Benutzerrollen – alle Benutzer mit den entsprechenden Berechtigungen können sie sehen und verwenden.
- Das Tagging-System ist universell und unterstützt nahezu alle Objektmodelle in OpenVLE.
