# System

Der Bereich **System** umfasst alle zentralen Verwaltungs- und Hintergrundfunktionen von OpenVLE.  
Hier findest du systemweite Protokolle, Aufgaben, Konfigurationen und Aktivitäten, die das Verhalten und den Betrieb der gesamten Plattform betreffen.

## Beispiel oder Anwendungsfall

<Example title="Systemaktivitäten prüfen">
  Eine Administratorin möchte nachvollziehen, wann Benutzer zuletzt Änderungen
  an VM-Vorlagen vorgenommen haben. Sie öffnet den Bereich **System →
  Aktivitäten** und filtert dort nach dem Objekt „VM-Vorlagen“. Anschließend
  kann sie genau sehen, welcher Benutzer welche Aktion wann durchgeführt hat.

## Hinweise / Besonderheiten

- Der Systembereich ist in der Regel nur für Benutzer mit erweiterten Berechtigungen sichtbar.
- Änderungen an globalen Einstellungen wirken sich auf alle Benutzer aus.
- Aufgaben und Aktivitäten können zur Analyse von Problemen oder zur Überwachung des Systemzustands genutzt werden.
- Die Protokollierung erfolgt fortlaufend – ältere Einträge können nach definierten Aufbewahrungsfristen automatisch gelöscht werden.
